This repository organizes career-focused cybersecurity labs from Learn SecByte into domain-specific paths to help security practitioners build verified, practical expertise.

Hands-on labs focused on penetration testing methodologies, offensive scoping, exploitation, C2 infrastructure, and professional vulnerability reporting:

* **Penetration Tester Fundamentals:** Mastering the end-to-end pen testing lifecycle from scoping rules of engagement to executive reporting.
  * Lab Link: https://learn.secbyte.org/ctf/penetration-tester-fundamentals-from-scoping-to-reporting
* **Red Team Operator Foundations:** Planning adversary emulation engagements, executing post-exploitation, and managing operational infrastructure.
  * Lab Link: https://learn.secbyte.org/ctf/red-team-operator-foundations

### Defensive Operations, DFIR & Detection
Practical security labs centered on SOC alert monitoring, memory/disk artifact analysis, threat hunting hypotheses, and custom SIEM rule creation:

* **SOC Analyst Journey:** Triaging security alerts, investigating indicators of compromise (IoCs), and conducting incident handovers.
  * Lab Link: https://learn.secbyte.org/ctf/soc-analyst-journey-alert-triage-to-incident-handover
* **Digital Forensics Analyst:** Performing forensic artifact acquisition, timeline analysis, and full incident reconstruction.
  * Lab Link: https://learn.secbyte.org/ctf/digital-forensics-analyst-from-triage-to-incident-reconstruc
* **Incident Responder Fundamentals:** Triage procedures, active threat containment, eradication, and post-incident analysis.
  * Lab Link: https://learn.secbyte.org/ctf/incident-responder-fundamentals-triage-to-containment
* **Threat Hunter:** Developing hunt hypotheses, pivoting across security telemetry, and identifying hidden adversary activity.
  * Lab Link: https://learn.secbyte.org/ctf/threat-hunter-from-signals-to-scenarios
* **Detection Engineer Essentials:** Writing robust Sigma/YARA rules, tuning SIEM detection analytics, and reducing false positives.
  * Lab Link: https://learn.secbyte.org/ctf/detection-engineer-essentials

## Learning Path

Select a targeted track below to align with your career goals:

1. **Defensive Operations Track (SOC / DFIR / Detection)**
   - Start with Security Fundamentals and SOC Analyst alert triage.
   - Advance to Digital Forensics, Incident Response containment, Threat Hunting, and Detection Engineering.
2. **Offensive Security Track (Pen Testing / Red Team)**
   - Build foundational skills in Penetration Testing methodologies and reporting.
   - Progress to advanced Red Team operator techniques and adversary emulation.
3. **Cloud & Engineering Track (DevSecOps / Cloud Security)**
   - Master DevSecOps pipeline automation and security controls.
   - Secure cloud IAM roles, log architectures, and cloud perimeter infrastructure.
4. **Mastery Capstone**
   - Complete the end-to-end Cybersecurity Capstone to validate practical expertise across attack and defense domains.

## How to Use the Labs

1. Choose your preferred career track or topic from the index table or categories above.
2. Launch the interactive target lab environment directly on Learn SecByte using the provided link.
3. Complete hands-on objectives using industry tools (e.g., SIEM consoles, forensic suites, terminal utilities, cloud CLI tools, and proxies).
4. Review post-lab summaries, detection signatures, and defense hardening guidelines to solidify practical skills.
